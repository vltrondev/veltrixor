## 🚀 Capacidades y Servicios
1. **Software Corporativo a Medida:** ERPs, CRMs dedicados, dashboards operativos en tiempo real y arquitecturas en la nube.
2. **Sitios Web para Negocios:** Plataformas de alta conversión, carga ultra rápida, diseño de clase mundial y SEO técnico.
3. **Integraciones de IA e I/O:** Agentes autónomos, conectores de APIs/Webhooks, chatbots inteligentes y automatización de flujos de trabajo.
4. **Productos Propios:** Incubación, despliegue y operación de herramientas SaaS especializadas (ej. DentalGrid).

---

## 🌐 Soporte Multilenguaje
- **Bilingüe:** Español (Principal / Predeterminado) e Inglés.
- Conmutador reactivo accesible desde la barra de navegación superior.
- Persistencia de selección en almacenamiento local (`localStorage`).

---

## 🛠️ Stack Tecnológico
- **Frontend:** React 19 + Vite 8
- **Estilos:** Vanilla CSS con sistema de tokens de diseño (`variables.css`)
- **Iconografía:** Lucide React + SVG Brand Icons
- **Tipografía:** *Space Grotesk*, *Plus Jakarta Sans*, *Outfit*
- **Backend / Auth:** Supabase Client

---

## 💻 Desarrollo Local
